description: Push to main and deploy to vercel
---
Follow these steps to deploy the application to Vercel and push changes to the main branch.

// turbo-all
1. Add all changes to git: `git add .`
2. Commit the changes: `git commit -m "deploy"` (or another appropriate commit message)
3. Push to the main branch: `git push origin main`
4. Deploy to Vercel: `npx vercel --prod`
